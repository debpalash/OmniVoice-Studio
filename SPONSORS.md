# Sponsors

OmniVoice Studio is free, open-source, and fully local — no accounts, no API
keys, no cloud. It's built by one developer plus the people who chip in to keep
it going. **Sponsors make sustained development possible**, and this page (plus
a logo slot inside the app and on the project site) is how we say thank you.

## What sponsors get

- **Your logo in the app** — shown in the in-app Sponsors section (Support page),
  grouped by tier and linking back to your site.
- **A credit in this README/SPONSORS.md** on GitHub.
- **A slot on the project site** as it grows.
- The warm feeling of keeping a private, local-first AI toolkit alive for
  everyone.

## Tiers

| Tier       | Logo placement                                  |
| ---------- | ----------------------------------------------- |
| `platinum` | Top of the in-app grid + README, largest logo   |
| `gold`     | In-app grid + README                            |
| `silver`   | In-app grid + README                            |
| `bronze`   | In-app grid + README                            |

Tiers only control display ordering and prominence — every sponsor gets a logo
slot. Amounts per tier are agreed case by case; open an enquiry below and we'll
find something that fits.

## Become a sponsor

- **In the app:** open **Support → Sponsors → Become a sponsor** (opens a
  prefilled GitHub issue you review and submit — nothing is sent automatically).
- **On GitHub:** [open a sponsorship enquiry](https://github.com/debpalash/OmniVoice-Studio/issues/new?labels=sponsor&title=Sponsorship)
- **Prefer to tip?** [Ko-fi](https://ko-fi.com/debpalash) works for individual
  supporters who'd rather buy a coffee than sign a deal.
